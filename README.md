# Video Downloader Web

Веб-приложение для скачивания видео

- **Бэк:** Python 3.10+ / FastAPI / yt-dlp / FFmpeg
- **Фронт:** React + TypeScript + SCSS (Vite)

## Возможности

- Скачивание в выбранном качестве (до 4K)
- Режим «только звук» (mp3)
- Очередь загрузок
- История загрузок с размером, датой
- Отмена загрузки
- Субтитры, метаданные, обложка
- Файлы сохраняются в системную папку «Загрузки»
